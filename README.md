# Examen Parcial - POO

Descripción: Ejercicio para practicar la programación orientada a objetos (POO) en PHP, trabajando clases, objetos, encapsulamiento, enumeraciones, constructores, métodos y validaciones.

## Enunciado

Tenemos una aplicación de baloncesto en la que registramos jugadores. De cada jugador tenemos los siguientes datos:

* Nombre
* Edad
* Altura
* Peso
* Posición o posiciones que puede ocupar.

Hay que registrar al menos cuatro jugadores e implementar dos funcionalidades:

1. **Jugadores Sub21:** crear una lógica que devuelva todos los jugadores que tengan 21 años o menos.
2. **Búsqueda por posición:** dada una posición concreta, devolver todos los jugadores aptos para jugar en esa posición.

## Tecnologías

* PHP
* XAMPP
* Visual Studio Code

## Instalación

1. Clonar el repositorio:

```text
git clone https://github.com/jordiartigues/Examen-Parcial.git
```

2. Abrir el proyecto con Visual Studio Code.

3. Para ejecutar el ejercicio desde la terminal, entrar en la carpeta del proyecto:

```text
cd "Examen Parcial"
```

4. Ejecutar el programa:

```text
php index.php
```
